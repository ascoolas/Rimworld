# 导演 Mod：安装与使用说明

这个 Mod 把 RimWorld 变成木偶剧场：你写一份剧本文件，Mod 按时间点让角色走位、转身，同时控制镜头、天气和时刻。
拍摄期间游戏不会发生任何随机事件，角色也不会自己乱动。

> 当前版本：v0.3。只支持 **RimWorld 1.6**。

---

## 一、安装（只需做一次）

### 1. 切换到 1.6 稳定版
Steam 库 → 右键 RimWorld → 属性 → 测试版 → 选“无”（或 1.6）。等 Steam 更新完成。

### 2. 订阅 Harmony
在 Steam 创意工坊搜索 **Harmony**（作者 Brrainz）并订阅。几乎所有 Mod 都依赖它。

### 3. 放入导演 Mod（推荐：GitHub Desktop，一次设置，以后一键更新）
1. 安装 **GitHub Desktop**（https://desktop.github.com），用你的 GitHub 账号登录。
2. File → Clone repository → 选 `ascoolas/rimworld_memorial_do_convento`，
   本地路径选一个好找的地方，例如 `D:\修道院纪事\rimworld_memorial_do_convento`。
3. 顶部 **Current branch** 切换到 `claude/director-mod-skeleton`（以后如果合并进 main，就切回 main）。
4. 打开克隆下来的文件夹，进入 `Tools`，双击 **`链接到游戏.bat`**，按提示回车。
   它会在 `RimWorld\Mods\MemorialDirector` 建一个“链接”，直接指向仓库里的 `Mod` 文件夹。
   （如果游戏的 Mods 里已经有旧的 MemorialDirector 文件夹，先把它改名备份，脚本会提示你。）

**以后每次更新**：在 GitHub Desktop 里点 **Fetch origin → Pull origin**，然后重启游戏。不用再下载 ZIP、复制、覆盖。

**你自己的东西也一样**：你写的剧本（`Mod\Scripts`）、导出的演员卡（`Mod\Actors`）直接就在仓库里。
在 GitHub Desktop 左下角填一句说明，点 **Commit**，再点 **Push origin**，我这边就能看到。

> 备用方法（不装 GitHub Desktop）：在 GitHub 网页上下载 ZIP，把 `Mod` 文件夹复制到
> `RimWorld\Mods\` 并改名为 `MemorialDirector`。每次更新都要重新下载覆盖。

### 什么时候要重启游戏
| 改了什么 | 要不要重启 |
|---|---|
| 剧本（`Scripts`）、演员卡（`Actors`） | **不用**。直接重新“检查 / 开拍”就读到新内容 |
| 程序（`1.6\Assemblies`）、定义（`Defs`）、贴图（`Textures`） | 要重启游戏 |

### 4. 启用
启动游戏 → 主菜单“Mod” → 勾选 **Harmony** 和 **修道院纪事 · 导演**，确保 Harmony 排在前面 → 重启游戏。

以后每次我更新 Mod，你只需要重新下载、**覆盖** `MemorialDirector` 文件夹即可。
（如果你在 `Scripts` 或 `Actors` 里放了自己的文件，覆盖前先备份；最好把它们也提交到仓库，见第七节。）

## 二、拍摄模式（自动生效）

启用 Mod 后，以下保护默认全部开启，可以在 **选项 → Mod 设置 → 修道院纪事 · 导演** 或导演面板里关掉：

| 选项 | 作用 |
|---|---|
| 静默叙事者 | 不触发任何随机事件：袭击、访客、商队、疾病、日食、动物发狂…… |
| 锁定天气 | 天气只由剧本里的 `<天气>` 指令改变 |
| 禁止精神崩溃和灵感 | 角色不会崩溃、不会突然获得灵感 |
| 禁止随机社交 | 不出现聊天气泡、不会吵架打架 |
| 冻结需求 | 饥饿、睡眠、娱乐等始终满值，角色不会去吃饭睡觉 |
| 演员待命 | 殖民者没接到指令时原地站着。你手动右键下的命令仍然有效，方便布景 |
| 显示格子坐标 | 鼠标旁边显示当前格子的坐标，写剧本时用 |
| 开拍时自动进入截图模式 | 开拍时隐藏所有界面（默认关闭） |
| 结束时暂停 | 剧本跑完后自动暂停 |
| 不弹取名窗口 | 不再弹出“给派系取名”“给殖民地取名” |
| 锁定镜头 | 开拍后键盘、鼠标拖动、滚轮都动不了镜头，只听剧本的；按 F8 停止后恢复 |
| 隐藏鼠标指针 | 开拍后鼠标指针消失，停止后恢复 |

> 注意：这个 Mod 只用于拍摄。请不要在正常游玩的存档里启用。

## 三、片场：开局、存档和复用

### 1. 一张地图 = 一个“布景存档”，可以反复用
- 不需要每个镜头开一局新游戏。一张地图搭好后存档，比如 `M9_路上`。
- 同一张地图上的所有镜头都用这个存档：**每拍一条之前读档**，拍完不存档。
  这样每次开拍时一切都和上次完全一样。
- 布景改了（多搭了一间房、换了季节），就另存一个新名字，比如 `M9_路上_夜`。
- 剧本里的 `<登场>` 会从演员库里把演员“请”出来，所以布景存档里**不用放演员**。

### 2. 开局一次设定好：用“剧本编辑器”做一个“片场”开局
RimWorld 没有真正的地图编辑器，但主菜单的 **剧本编辑器**（开局时“选择剧本”页面左下角的“剧本编辑器”）可以把开局条件固定下来，存成文件，以后每次新开布景都选它：
1. 选“编辑器”，以“坠机求生”为底，改名为 `修道院纪事·片场`。
2. 开局人数改为 **1**（这个人只是占位，放在地图角落，不入镜；不要删掉他，殖民地里一个人都没有会触发游戏结束）。
3. 删除全部开局物品、开局动物、开局科技以外的杂项；“到达方式”改为“站在地上”。
4. 点“保存”，存成文件。以后新开地图都选这个剧本。
5. **文化（Ideology）**：开局时创建一次“1711 年的天主教”文化，在文化编辑器里点“保存”存成文件；以后每次开局点“读取”即可。也可以选“不使用文化”。
6. **地图**：开局选地点时点“高级”，可以设地图大小（250×250）和开局季节。
7. 叙事者随便选：导演 Mod 会屏蔽所有事件。

### 3. 演员库：长期使用的角色
主角的外貌、服装、伤残都存成“演员卡”（`Mods\MemorialDirector\Actors\*.xml`）。
同一张卡每次生成的人**一模一样**，在任何存档里都能用。现在有三张：巴尔塔萨、布里蒙达、洛伦索神父。

- **在剧本里使用**：`<登场 秒="0" 角色="巴尔塔萨" 到="120,80" 面向="南"/>`。
  地图上还没有这个人，就按演员卡生成；已经有了，就瞬移到这个位置。
- **手动放到地图上**：导演面板 → 演员库 → “放到地图上” → 点地图上的格子。
- **调整长相**：卡里没写的部分（脸型、发型、胡子）由卡上的“种子”数字决定。种子不变，长相就不变。
  想换长相，有两种办法：
  1. 改种子数字，重新登场，挑到满意的为止；
  2. 在游戏里用造型台（或人物编辑器类 Mod）把这个人改好，选中他，在演员库点 **“选中角色存为演员卡”**，会覆盖同名演员卡，把发型、胡子、肤色、服装、伤残全部记下来。
- **背景故事**：演员卡上的 `童年=` 和 `成年=` 决定角色信息卡里的背景。三位主角用的是本 Mod 按原著写的专属背景（如“马夫拉农家子 / 独手的退伍步兵”“塞巴斯蒂安娜的女儿 / 七个月亮”“巴西神童 / 飞行家神父”），定义在 `Mod\Defs\Backstories_Main.xml`。也可以填游戏自带背景的内部名字；不知道内部名字，就在游戏里给角色换好背景后用“存为演员卡”导出。
- **义肢**：巴尔塔萨默认是空着的断腕。剧本里用 `<换义肢 角色="巴尔塔萨" 类型="铁钩"/>`，`类型` 可以写 铁钩 / 长钉 / 无。铁器会画在人物左手的位置，随朝向变化。

## 四、拍一场戏的流程

1. **布景**：开发者模式（选项里开启）+ 上帝模式，摆好建筑、家具、角色位置。存档，例如 `EP01_场景03_罗西奥广场`。
2. **写剧本**：在 `Mods\MemorialDirector\Scripts\` 里新建一个 `.xml` 文件（可以建子文件夹，例如 `Scripts\EP01\`）。
   推荐用 **Notepad++** 或 **VS Code** 编辑，保存编码选 **UTF-8**。
3. **检查**：游戏里点屏幕底部的 **导演** 按钮 → 选中剧本 → **检查剧本**。有错误会列出行号和原因。
4. **开拍**：先打开录屏软件（OBS），再点 **开拍**（或按 **F7**）。
   想隐藏界面，按“切换截图模式”的快捷键（选项 → 按键设置里可以查看）。
5. **出错**：按 **F8** 停止 → 读档 → 改剧本 → 再拍。剧本文件改完后不需要重启游戏，直接再点“开拍”即可。

## 五、剧本怎么写

一份剧本就是一串带时间的指令。最小的例子：

```xml
<?xml version="1.0" encoding="utf-8"?>
<剧本 名称="第一场">
  <镜头 秒="0" 对准="125,125" 缩放="远"/>
  <走   秒="2" 角色="布里蒙达" 到="122,125"/>
  <结束 秒="10"/>
</剧本>
```

规则：
- 每条指令写成 `<指令名 属性="值" 属性="值"/>`，注意末尾的 `/>`。
- 引号必须是英文半角引号 `"`，不能是中文引号 `“”`。
- `秒` 是从开拍算起的时间。可以写 `12`、`2.5`，或 `1:05`（1 分 5 秒）。
  **不写 `秒` 表示和上一条指令同时执行。**
- 指令按时间执行，书写顺序不要求严格按时间，但按时间写更容易读。
- 坐标写成 `x,z`，就是鼠标旁边显示的那两个数字。
- 角色名可以写游戏里的昵称、名、姓或全名。
- `<!-- 这样写 -->` 是注释，游戏会忽略。
- 没写 `<结束>` 的话，最后一条指令执行后 10 秒自动结束。

### 指令一览（v0.1）

| 指令 | 属性 | 说明 |
|---|---|---|
| `<镜头>` | `对准`：坐标或角色名<br>`缩放`：见下表，或数字 2.5–80<br>`用时`：秒，不写就是硬切 | 移动镜头。写了 `用时` 就是平滑推拉摇移 |
| `<跟随>` | `角色`<br>`缩放`、`用时`（可选） | 镜头一直跟着这个角色 |
| `<停止跟随>` | 无 | 镜头停在当前位置 |
| `<走>` | `角色`<br>`到`：坐标，或另一个角色名（走到他/她身边并面向对方）<br>`步态`：漫步 / 慢走 / 正常 / 跑（默认“正常”）<br>`面向`：到达后面向哪里（坐标、角色名、北/南/东/西） | 走位 |
| `<面向>` | `角色`<br>`目标`：坐标、角色名，或 北/南/东/西（也可以写 上/下/右/左） | 转身。面向另一个角色时，对方移动也会一直跟着看 |
| `<天气>` | `类型`：晴 / 雾 / 雨 / 雾雨 / 雷雨 / 干雷暴 / 小雪 / 大雪<br>`渐变`：是（不写就是立刻切换） | 改天气 |
| `<时刻>` | `小时`：0–23 | 把时间往后拨到当天（或第二天）的这个钟点 |
| `<登场>` | `角色`：演员卡里的名字<br>`到`：坐标<br>`面向`：北/南/东/西 | 让演员出现在某个格子（没有就按演员卡生成，有就瞬移过去） |
| `<退场>` | `角色` | 让角色从地图上消失 |
| `<换义肢>` | `角色`<br>`类型`：铁钩 / 长钉 / 无<br>`部位`：默认“左手” | 换上或摘下义肢 |
| `<结束>` | 无 | 剧本结束 |
| `<注释>` | `内容` | 什么也不做，给自己看的备注 |

方向说明：地图上方是“北”，右边是“东”。

**缩放**：数字表示画面上下一半能装下多少格，和调度剧本里的 size 是同一个意思。

| 写法 | 数值 | 对应调度剧本 |
|---|---|---|
| 特写 | 4 | CU 特写 3–4.5 |
| 近景（或“近”） | 6 | MCU 近景 5–6 |
| 中景（或“中”） | 8 | MS 中景 7–9 |
| 全景 | 14 | WS 全景 10–18 |
| 大全景（或“远”） | 28 | EWS 大全景 20–35 |
| 鸟瞰 | 40 | AERIAL 35+ |

也可以直接写数字，比如 `缩放="10"`，范围是 2.5 到 80（游戏原本只能 11 到 60，导演 Mod 放宽了）。

示例剧本：
- `Scripts/00_走位测试.xml`：走位、转身、镜头。
- `Scripts/01_演员与义肢演示.xml`：三位主角从演员库登场，巴尔塔萨轮流换铁钩、长钉。
- `Scripts/EP01/E01-S06-SH60_路上.xml`：**第一集样片**，巴尔塔萨沿路向西走，镜头跟随后拉高。

## 六、出问题怎么办

1. 游戏里打开开发者模式后，屏幕上方有日志按钮，红色的是错误。
2. 把这个文件发给我（或把里面带 `[导演]` 的内容贴给我）：
   ```
   %USERPROFILE%\AppData\LocalLow\Ludeon Studios\RimWorld by Ludeon Studios\Player.log
   ```
   （在 Windows 资源管理器地址栏粘贴这个路径就能打开。）
3. 同时告诉我：用的哪个剧本、在第几秒出的问题、看到了什么现象。

## 七、文件放在哪里

- 我（写代码的 Agent）只能看到 GitHub 仓库和你在对话里上传的文件，看不到 claude.ai 项目档案库里的内容。所以**一切以仓库为准**：大纲、剧本、旁白、演员卡、剧本文件都放进仓库。
- 仓库里的 `Mod/Actors` 和 `Mod/Scripts` 就是游戏里用的那两个文件夹。你在游戏里导出的演员卡、自己写的剧本，请上传到仓库对应的位置，下次我更新 Mod 时就不会丢。

## 八、已知限制

- 拍摄中途存档、读档后，剧本不会接着播放，需要重新开拍。
- `<时刻>` 只能往后拨，不能倒回去。
- 目前只有你自己阵营的人（殖民者）会“待命”。其他阵营的人（群众演员）会在后续版本支持。
- 演员卡里的服装用的是原版和 DLC 的衣服染色，还不是专门做的 1711 年服装；专门的服装后面逐件做。
- 镜头没有旋转，也没有人物特写和表情，这是 RimWorld 本身的限制。
