一、全局约定
------------------------------------------------------------------
1. 平台：RimWorld 1.6 + Harmony；已装全部 DLC（Royalty / Ideology / Biotech / Anomaly / Odyssey）。
   Mod 暂名 MemorialDirector，以下简称“导演”。
2. 坐标：RimWorld IntVec3 (x,z)，原点在地图西南角，x 向东，z 向北。
   本文给出的坐标是“建议值”。每张地图里关键位置用【锚点】命名（如 K_ModelTable_S）。
   导演 Mod 需提供“锚点”工具：开发者模式下放置不可见的命名标记，随存档保存；
   脚本一律优先按锚点名寻址，坐标只作为找不到锚点时的后备。这样布景微调后脚本不用改。
3. 时间：剧本时间码格式 mm:ss.s，从本集第一帧算起。
   游戏以 1× 速度（60 tick/秒）运行录制；导演按“镜头起点 + 相对秒数”调度。
4. 镜头参数：
   pos (x,z) = CameraDriver 的 rootPos；size = rootSize（正交半高，单位格）。
   预设：CU 特写 3–4.5｜MCU 近景 5–6｜MS 中景 7–9｜WS 全景 10–18｜EWS 大全景 20–35｜AERIAL 鸟瞰 35+。
   vanilla 的缩放下限约 11，导演必须放开到 2.5–80（Harmony 改 CameraDriver 的缩放范围配置）。
   动作：CUT 硬切｜PAN 平移（指定目标 pos 与时长）｜PUSH/PULL 推拉（改 size）｜RISE 拉高（size 增大并保持跟随）
         FOLLOW 跟随角色（可带偏移）｜FIX 固定｜SHAKE 震动｜FADE_IN/FADE 淡入淡出（黑）｜CUT_BLACK 硬切黑。
   缓动默认 easeInOut。
5. 录制：UI 全隐藏（含名字标签、选择框、气泡以外的一切界面）；1920×1080 或 3840×2160，60fps；
   游戏声音单独录一轨（或静音，后期配声）。每个存档录完一个场景，导演输出时间码日志（见第七条）。
6. 存档：每场一个存档，命名见各场标题。场内的“子存档”是同一地图不同布置或不同地图的插入镜头。
7. 时间码日志：导演每执行一个镜头，在 /MemorialDirector/logs/ 写一行
   shot_id, 计划起点, 实际起点(真实时间), 实际时长, 存档名
   剪辑时按 shot_id 对齐旁白与字幕。
8. 无随机：导演运行期间关闭全部随机事件、需求衰减（饥饿、睡眠、娱乐、心情）、精神崩溃、社交互动、
   小人自主 AI。小人只执行脚本指令；脚本没给指令时原地站立（可选 idle_sway 微动）。


二、导演指令表（剧本里出现的全部动词，开发需逐一实现）
------------------------------------------------------------------
【场景与环境】
  LOAD save                       载入存档（录制前人工载入亦可）
  TIME hh:mm [→ hh:mm, 秒]         锁定或快进一天中的时刻。【猜测】实现：自定义 GameCondition 覆盖 SkyTarget，
                                   而不是真的推进游戏时间，避免作物、温度、需求被时间推动。
  WEATHER def                      立即切换天气（WeatherManager.TransitionTo 并把过渡时长设为 0）
  SEASON 春|夏|秋|冬                只改地表与植物外观，不改温度
  LIGHT override(颜色,强度)          叠加天光颜色，如日落金色
  FILTER none|dream|dream_gold|dream_red|chronicle|memory   全屏后处理：
         dream = 降饱和 + 暗角 + 轻微模糊 + 缓慢波动；dream_gold = dream 偏暖金；dream_red = dream 偏暗红；
         chronicle = 暖褐 + 纸张颗粒 + 暗角（“据说”的轶事）；memory = 灰褐 + 轻微闪烁（角色口述的往事）
  SPAWN / DESPAWN 角色或物件 @锚点 [FACE 方向]
  OPEN / CLOSE 门
【角色】
  MOVE 角色 → 锚点 [speed=walk|jog|run|数值格/秒]   寻路行走；必须能按“期望到达时刻”自动调速
  FACE 角色 N|E|S|W|目标
  POSE 角色 stand|sit|kneel|prone|lie       kneel 为自制：身体贴图下移 0.15 格并纵向压缩 0.85；prone = 俯卧
  LAYDOWN 角色 床位|地面                   vanilla 躺下（睡姿）
  WANDER 角色组 区域 [时长]                 在区域内随机走动，脚本控制随机种子以保证可复现
  FOLLOW 角色 目标 距离 / FLEE 方向 / BACKOFF 格数 / JOG
  ATTACH / DETACH 角色 → MovingProp 槽位   上下车船；ATTACH 后角色绘制在道具上，随之移动
  MOUNT 骑手 坐骑 / GALLOP                   骑乘（vanilla 无骑乘，自制：骑手绘制在马上方，作为 ATTACH 的特例）
  GIVE 甲 → 乙 物品 / HOLD 物品 / STOW 物品入背袋 / DROP / CARRY / THROW / DRAG 尸体
  EAT 物品                                  吃的动作（vanilla 进食动画+fleck），不改需求
  DRAFTED 角色 on|off                       仅用于显示手持武器（UI 已隐藏，不会出现征召界面）
  MELEE / SHOOT 目标                        vanilla 战斗动作，命中结果由脚本决定（不随机）
  DAMAGE 伤害类型 → 身体部位 [致死]          直接施加伤害，例如 Gunshot→LeftHand
  KILL 角色 [伤害类型]
  HEDIFF add|remove|swap 名称 → 部位         义肢切换就用 swap
  APPAREL 角色 换装 A→B
  MUTE 角色                                 之后不再允许该角色出现气泡
【动画】（vanilla 没有的都用“绘制偏移/旋转/缩放”的补间实现，不需要骨骼动画）
  bow 前倾 15°｜nod 点头｜headshake 摇头｜wave 挥手｜tremble 抖动｜stagger 踉跄｜stumble 绊｜recoil 后仰
  flinch 缩一下｜shove 侧让｜slap 自打耳光｜flagellate 自笞｜bless 祝福｜knock 敲门｜bite 用牙绑义肢
  interact 摆弄身前物件｜place / pick 放置/拿起｜extend 前伸｜lean 俯身｜stretch 伸懒腰｜row 划桨
  hop 鹳式跳｜drop / climb 从高处落下/爬上｜wake 坐起｜rear 马立起｜knockdown 被击倒｜look_up / look_around
  idle_sway 原地微动｜jiggle 物件抖动｜chop 剁肉｜hold 扶住他人｜help 搀扶｜step_on 踩脚｜shrug 耸肩｜push 推搡
【气泡与粒子】
  MOTE 角色 speech|laugh|pray|anger|tears|assobio|urro|'!'|'?'|自制图标
    speech 用 vanilla 社交互动图标，只表示“谁在说话”，不显示文字。台词全由旁白讲述。
  FLECK 类型 位置                            自制粒子见资产表
  PLAY 效果器                                 vanilla 或 DLC 的 Effecter，如手术、仪式演讲
【镜头】见第一节第 4 条。
【时间码规则】
  每个镜头：起点 = 上一镜终点；时长 = pre + 本镜旁白总时长 + post。
  每条旁白：时长 = 实际音频时长（无音频时按 2.7 词/秒估算）+ 句后停顿。
  镜头内的相对时刻写作 “+Ns”，或写作“在旁白某词处”：导演可以用词级时间戳（TTS 一般能导出）或按词数比例近似。
